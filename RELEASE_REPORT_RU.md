# Modern Field Moves v1.1.0 — отчёт

Добавлен map_cursor.lua, общий для RBY и G/S/C. Изменены подключение в main.lua,
настройки field_user.lua, обработка карты town_map.lua, manifest и документация.
Код HM в gen2.lua и lighting.lua не менялся.

FREE использует родные карты и метки, движение четырьмя направлениями,
повтор при удержании и ограничение по краям. CLASSIC сохраняет перебор v1.0.
Новая настройка сохраняется штатным менеджером; default FREE. Старые настройки
не сброшены. В кеше без координат используется CLASSIC.

Пройдено 4567 локальных проверок: Red 543, Blue 543, Yellow 556,
Gold 979, Silver 979, Crystal 967. LuaJIT 2.1 и настоящий код движка commit
 e2114f7c85795d52903ea98deab493a4f181bace, синтетические данные и заглушки графики.
Проверены оба режима, четыре направления, пустые клетки, посещения, Fly YES/NO,
возврат, границы, удержание, сохранение настройки и регрессия HM/LIGHT/QoL.

Ограничение первой версии: метки — точки, области длинных дорог не размечены.
В Gen 2 наведение допускает два пикселя вокруг реальной координаты. Произвольные
клетки моря не приписываются ближайшему городу. При совпадении меток выбирается
первая в стабильном порядке данных (Gen 2 — по индексу).

Полный ROM/визуальный прогон не выполнялся. Сборка готова для пользовательской
проверки FREE, но совпадение наведения с изображением каждой реальной карты
нужно проверить в игре. Ручные пункты в MANUAL_CHECKLIST_RU.md не выполнены.
