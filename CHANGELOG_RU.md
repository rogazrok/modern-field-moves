# Изменения Modern Field Moves

## v0.9.0 — Modern Field Moves, финальные настройки

- Публичное название изменено на Modern Field Moves. Внутренний ID
  surf_without_hm_red сохранён для обновления без сброса настроек.
- FIELD MOVE USER: GENERIC по умолчанию, KNOWN MOVE с fallback на GENERIC,
  FIRST PARTY. Сохранены обезличенные сообщения и штатные эффекты HM.
- HM REQUIREMENT: добавлен UNRESTRICTED — debug/cheat option, отключающий
  требования диска и значка только для полевых HM. HM + BADGE остаётся default,
  BADGE ONLY сохранён. Реальные предметы, значки и сюжетные флаги не выдаются.
- CONFIRM PROMPTS: ON по умолчанию; OFF пропускает подтверждения Cut, Surf,
  Strength, Whirlpool и Waterfall при взаимодействии с подходящим объектом.
- Подтверждение Fly обязательно всегда, в том числе при OFF + UNRESTRICTED.
  Сохранены посещённые точки и ограничения мира. Карта всё ещё требует
  настоящий Town Map / Map Card и сохраняет просмотр дорог после открытия Fly.
- LIGHT MANUAL/AUTO и отдельный явный Flash в Ruins of Alph сохранены.
- Старые настройки читаются без миграции и сброса; новое значение по умолчанию ON.
- Поддерживаются только Red, Blue, Yellow и Crystal. Gold/Silver запланированы
  для v1.0 и не включены в manifest v0.9.0.
- 2518 локальных проверок. Полный игровой прогон с ROM не выполнялся.

## v0.8.1 — полная карта при открытом Fly

- RBY и Crystal: разблокировка Fly больше не переключает карту в ограниченный
  список мест посадки. Сохраняются родные дороги, города и названия локаций.
- Вверх/вниз перебирают все доступные для просмотра локации обычной карты.
  A предлагает перелёт только на разрешённой посещённой Fly-точке.
- На дороге или недоступном городе A не вызывает перелёт или предупреждение.
- Сохранены обязательное подтверждение, позиция курсора при отказе, ограничения
  региона, проверки перед вылетом и штатная анимация. LIGHT и другие HM не изменены.
- 1527 локальных проверок прошли. Полный игровой прогон с ROM не выполнялся.

## v0.8.0 — контекстный LIGHT и автоматическое освещение

- Постоянный FLASH заменён на LIGHT только в настоящей неосвещённой тёмной
  области при разблокированном Flash. После освещения пункт исчезает.
- Добавлен LIGHT MODE: MANUAL / AUTO, по умолчанию MANUAL, включая старые saves.
- AUTO освещает обычные тёмные пещеры без диалога, дождавшись безопасного состояния
  игрока. Обычная ночь не считается темнотой для Flash.
- Crystal: используется чистая проверка палитры и flashUsed без опроса
  availableFieldActions и без callback стены Aerodactyl.
- Особый FLASH в комнате Aerodactyl остаётся отдельным явным действием до
  открытия стены. AUTO LIGHT никогда не запускает эту загадку.
- Ручной LIGHT сохраняет FLASH was used! и режимы KNOWN MOVE / FIRST PARTY.
  Требования HM, карта, Fly и остальные полевые действия сохранены.
- 1504 локальные проверки прошли для RBY и Crystal. Полный игровой прогон
  с ROM не выполнялся; необходима проверка в игре.

## v0.7.0 — карта независима от Fly

- Карта теперь независима от Fly: получение карты открывает просмотр через START.
- RBY: TOWN MAP разблокируется получением настоящего Town Map у Daisy.
  Учитывается постоянный EVENT_GOT_TOWN_MAP; для старых состояний сохранения
  также принимается предмет в Bag или PC. Сдача в PC сохраняет доступ.
- Crystal: MAP разблокируется получением Map Card для Pokégear у Guide Gent
  в Cherrygrove. Сохранено короткое название, помещающееся в родное меню.
- Fly становится функцией уже существующей карты после получения HM02 + Badge.
  Сохранена настройка BADGE ONLY: она отменяет только требование HM02 для
  перелёта, но не требование получить саму карту.
- Без доступного Fly, в помещениях и при отсутствии доступных пунктов открывается
  обычная карта без предупреждений о невозможности перелёта.
- Сохранены обязательное YES/NO, родные анимации, посещённые пункты и ограничения
  регионов. Перед вылетом требования и доступность города проверяются повторно.
- Миграция прогресса и новая игра не нужны. Настройки FIELD MOVE USER,
  GENERIC-сообщения и остальные HM сохранены. LIGHT/Flash не перерабатывались.
