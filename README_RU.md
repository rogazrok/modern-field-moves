# Field Moves — RBY & Crystal v0.6.1

Все семь HM Pokémon Crystal без обучения покемонов. Сохранена поддержка
пяти HM Red, Blue и Yellow. Gold и Silver в этой версии не включены.
По умолчанию для каждой способности нужны её диск и соответствующий значок.
Другие моды не обязательны. Mod API 2.

Выполнены этапы 1–4 из порядка реализации: обезличенные сообщения, выбор
исполнителя, настройки требований и замена FLY в START на TOWN MAP.
Переделка Flash в LIGHT, автоматический свет и переключатель подтверждений
остаются для следующих этапов.

## Установка и обновление

1. Импортируйте field_moves_rby_crystal-v0.6.1.zip через MODS → Import mod .zip.
2. Замените предыдущую версию. ID и папка остаются surf_without_hm_red:
   создавать вторую копию мода не нужно.
3. В списке модов выберите Crystal через Show for и включите
   Field Moves - RBY & Crystal.
4. Полностью перезапустите игру и используйте сохранение именно Crystal.

Для ручной установки замените содержимое прежней папки мода. В проверенной
установке пользователя это %APPDATA%\pokemon-love2d\mods\surf_without_hm_red\.
У portable-сборок каталог может отличаться.

В папке должны находиться manifest.json, main.lua, gen2.lua, field_user.lua и town_map.lua.
README_RU.md — инструкция. При переносе мода копируйте все пять рабочих файлов.

Сохранено разрешение engine_internals из v0.4.0. Оно нужно для штатного
меню Fly и запуска Flash в Crystal, а также для изменения сообщений внутри
полевых действий. Если менеджер модов
покажет запрос на это разрешение, разрешите его для работы адаптера.
Мод вызывает внутренние функции движка; файлы самой игры не заменяет.

## Настройки: MODS → Field Moves - RBY & Crystal → OPTIONS..

Используется штатное меню настроек самого мода. Нового пункта SETTINGS в START нет.
Настройки читаются при использовании способности; перезапуск для их переключения
не нужен. После замены файлов самого мода перезапуск обязателен.

| Настройка | Значение | Поведение |
| --- | --- | --- |
| FIELD MOVE USER | GENERIC — по умолчанию | Сообщение CUT was used!, SURF was used! и т. п., без имени покемона |
| FIELD MOVE USER | KNOWN MOVE | Первому покемону, действительно знающему приём, приписывается действие: BLASTOISE used SURF!; если такого нет — GENERIC |
| FIELD MOVE USER | FIRST PARTY | Имя первого покемона команды независимо от атак; яйца в Crystal пропускаются |
| HM REQUIREMENT | HM + BADGE — по умолчанию | Полученный HM и соответствующий значок обязательны |
| HM REQUIREMENT | BADGE ONLY | Требуется только соответствующий значок |

Сообщения разбиваются на две строки в духе оригинальной игры: например,
SURF / was used! или BLASTOISE used / SURF!. Strength также использует
обезличенную вторую реплику в режиме GENERIC. Отдельного сообщения «FLY was used!» нет.

HM остаются обычными атаками: их можно учить и использовать в бою.
Режим FIELD MOVE USER не меняет требования прогресса. Даже KNOWN MOVE
не требует обучать команду — без знатока применяется GENERIC.
NO REQUIREMENTS отсутствует. Ни один режим не отменяет штатные ограничения
местности, состояния игрока и доступных пунктов Fly.

Старые сохранения подходят без новой игры. Если настроек ещё нет, используются
безопасные значения GENERIC и HM + BADGE. Выбор хранит сам менеджер модов;
мод не выдаёт предметы, не меняет значки, сюжетные флаги, атаки, PP или HP.

## Crystal: требования и управление

| Способность | Диск | Значок | Использование |
| --- | --- | --- | --- |
| Cut | HM01 | Hive — Bugsy | A у дерева → подтверждение |
| Fly | HM02 | Storm — Chuck | START → MAP → город → YES/NO |
| Surf | HM03 | Fog — Morty | A у воды → подтверждение |
| Strength | HM04 | Plain — Whitney | A у валуна → подтверждение, затем толкать |
| Flash | HM05 | Zephyr — Falkner | START → FLASH |
| Whirlpool | HM06 | Glacier — Pryce | Во время плавания A перед водоворотом |
| Waterfall | HM07 | Rising — Clair | Во время плавания A перед водопадом, лицом вверх |

Диск учитывается в сумке или PC. Положить его в PC можно без потери способности.
В режиме HM + BADGE один значок без диска или один диск без значка способность не открывают.
Мод не выдаёт диски и не меняет задания, за которые их получают.
В Crystal проверяется наличие HM в сумке/PC: если удалить его редактором
из обоих хранилищ, доступ в HM + BADGE пропадёт. Обычные HM многоразовые и не выбрасываются.

В START Crystal добавляются только MAP и Flash, когда выполнены требования.
Cut, Surf, Strength, Whirlpool и Waterfall используют существующие в Crystal
взаимодействия с окружением. Состояние Strength, движение по воде, ограничения
местности и анимации обслуживает движок. Fly использует его список доступных
посещённых пунктов и ограничения региона. Flash сохраняет особое применение
в комнате Aerodactyl в Ruins of Alph; простое открытие START не активирует его.

## TOWN MAP: перелёт через карту

В RBY строка FLY в START заменена на TOWN MAP, в Crystal — на MAP.
Порядок: START → TOWN MAP → выбрать город → FLY to <город>? → YES / NO.
В RBY открывается родная карта Канто; в Crystal — родная региональная карта
движка на основе Pokégear. Отдельного нового экрана или списка городов мод не рисует.

A выбирает пункт и открывает стандартное подтверждение. NO или B в подтверждении
возвращает на ту же карту с тем же выбранным городом. B на самой карте закрывает её.
YES запускает штатный перелёт с исходной анимацией. Перед вылетом снова проверяются
требования, допустимость перелёта из текущего места и доступность города.

На этом этапе TOWN MAP появляется только после разблокировки Fly согласно
HM REQUIREMENT: HM02 + значок по умолчанию или только значок в BADGE ONLY.
Это пока карта для перелёта: в помещениях перелёт и открытие этого пункта
отклоняются штатной проверкой. Режим обычного просмотра карты до разблокировки
способности в этой версии не добавлен. Штатные способы просмотра карты остаются.
Доступны только разрешённые движком посещённые Fly-точки; в Crystal сохранены
родные ограничения выбора карты Джото/Канто. Подтверждение перелёта обязательно.

## Исполнитель способности

По умолчанию сообщения обезличены. Для выполнения штатных действий движку
всё ещё передаётся покемон команды, но в GENERIC его имя не показывается.
Нужна непустая команда, а в Crystal — хотя бы один покемон, не являющийся яйцом.
В GENERIC сохраняется прежний выбор для родной анимации: знающий приём,
иначе первый. В KNOWN MOVE имя показывается только при реально выученной атаке;
FIRST PARTY выбирает первого независимо от атак. Совместимость вида с HM не нужна.

## Quality of Life

Проверена логика с Quality of Life 1.3.0
(unxpected-uxp/pokemon-gen1-recomp-mod-qol). Настройки QoL мод не меняет.

В Crystal используется родной обработчик взаимодействий; наш дополнительный
Gen 1 обработчик кнопки A там не запускается. При включённом меню воды QoL
сначала можно выбрать Surf или удочку. После выбора Surf открывается штатное
подтверждение Crystal, до начала плавания. Это последовательные действия;
скрытого второго диалога после начала плавания быть не должно. При выключенном
QoL остаётся штатный вопрос Crystal. Во время обычного плавания Surf повторно
не предлагается; взаимодействия с водоворотами и водопадами остаются доступны.

Для RBY сохранены прежние исправления: один обработчик водного меню, Strength
по A у валуна, отсутствие Cut/Surf/Strength в START. QoL может выполнять
Cut и Strength сразу, в соответствии со своими настройками.

## Red, Blue и Yellow

| Способность | Диск | Значок | Использование |
| --- | --- | --- | --- |
| Cut | HM01 | Cascade — Misty | A у дерева |
| Fly | HM02 | Thunder — Lt. Surge | START → TOWN MAP → город → YES/NO |
| Surf | HM03 | Soul — Koga | A у воды |
| Strength | HM04 | Rainbow — Erika | A у валуна |
| Flash | HM05 | Boulder — Brock | START → FLASH |

В Gen 1 получение диска учитывается по штатному сюжетному флагу или наличию
предмета в сумке. Полученный обычным способом HM можно хранить в PC.
В Yellow выбор спрайта Surf Пикачу и скрытие сопровождающего покемона
обслуживаются штатной логикой движка. Атаки Пикачу мод не меняет.

## Короткая проверка в Crystal

1. Без нужного диска или значка способность не должна срабатывать.
2. С диском и значком проверьте A у дерева, воды и валуна, не обучая команду HM.
   Попробуйте отказ и подтверждение; Surf не должен спрашивать повторно в воде.
3. Проверьте HM06 у водоворота и HM07 перед водопадом, находясь на воде.
4. В START Crystal должны быть только MAP/FLASH из полевых способностей мода.
   Выберите город на карте: до YES перелёт не должен начинаться. NO и B в
   подтверждении оставляют карту с прежним выбором. Затем подтвердите перелёт.
5. В тёмной пещере выберите Flash. Положите HM в PC и повторите проверку доступа.
6. При установленном QoL проверьте выбор Surf, удочки и отмену водного меню.
7. В OPTIONS.. мода переключите FIELD MOVE USER. GENERIC не должен показывать
   имя; KNOWN MOVE использует имя знатока либо GENERIC; FIRST PARTY — первого
   покемона (кроме яйца). Проверьте также вторую реплику Strength.
8. С одним значком и без HM переключите HM REQUIREMENT на BADGE ONLY:
   способность должна стать доступной. Верните HM + BADGE — снова недоступна.
   Без значка оба режима должны отказывать.
9. Перезапустите игру: выбранные настройки должны сохраниться. Начинать заново не нужно.

## Проверки и совместимость

Проверено по исходникам gen1recomp dev, commit
e2114f7c85795d52903ea98deab493a4f181bace. Внутренние интерфейсы Crystal могут
меняться в последующих версиях движка.

Для базовой v0.6.0 пройдено 1248 локальных проверок под LuaJIT 2.1: 907 для RBY и 341 для Crystal. После правки надписей v0.6.1 повторены 159 проверок Crystal и 51 проверка меню/перелётов Red.
Для Crystal проверены загрузка в sandbox с разрешением engine_internals,
manifest, все семь HM и значки, хранение в PC, яйца, штатные взаимодействия,
очередь Fly/Flash, закрытие START, родная карта Fly, логика комнаты Aerodactyl
и совместимость водного меню QoL. Дополнительные проверки v0.5.0 проверяют
реальные сообщения всех HM, три режима пользователя, оба режима требований,
отложенную реплику Strength, возврат к GENERIC, штатный менеджер настроек,
повторную загрузку сохранённых значений и отсутствие изменений прогресса при
переключении настроек. В RBY проверяется восстановление исходного каталога
текстов даже после ошибки в вызываемом обработчике. В Crystal выбранные
требования также проверены на пути запуска выученного HM из меню покемона.
В v0.6.0 добавлены проверки TOWN MAP: настоящие карты обоих поколений,
YES/NO и B через штатные виджеты, сохранение выбора при отказе, выход с карты,
повторная проверка требований и доступности города перед вылетом, ограничения
помещений, пустые списки пунктов и региональные ограничения Crystal.

Использован настоящий код движка, синтетические данные и заглушки графического
окружения. Выполнение анимаций заменено контрольными вызовами. Полный игровой
прогон Crystal с ROM здесь не выполнялся: архив готов к проверке в игре,
но локальные проверки не заменяют её.

## Исправление v0.6.1: размещение текста Crystal

В Crystal название сокращено до MAP, подсказка — Choose a / town.
Родное меню допускает семь символов в названии и десять в строке подсказки.
Обе строки теперь помещаются в своей области. Шрифт, рамки и размер интерфейса
не меняются. В RBY название TOWN MAP сохранено. Перелёты и настройки прежние.
