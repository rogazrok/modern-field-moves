# Modern Field Moves v1.0.0

Modern Field Moves — modern HM mechanics with the classic Pokémon feel.

HM и полевые способности без обязательного обучения покемонов для
**Pokémon Red, Blue, Yellow, Gold, Silver и Crystal** на gen1recomp, Mod API 2.
Gen 1 поддерживает пять HM; Gen 2 — все семь, включая Whirlpool и Waterfall.

## Установка и обновление с 0.9.x

1. Импортируйте `modern_field_moves-v1.0.0.zip` через MODS → Import mod .zip.
2. Замените прежнюю версию, не создавая вторую копию.
3. Выберите игру через Show for и включите Modern Field Moves.
4. Полностью перезапустите игру. Используйте сохранение соответствующей версии.

Внутренний ID и папка `surf_without_hm_red` сохранены. Новая игра и миграция
сохранений не нужны; значения прежних настроек не сбрасываются.
Для ручной установки замените содержимое прежней папки мода. В проверенной
установке это `%APPDATA%\pokemon-love2d\mods\surf_without_hm_red\`;
portable-сборки могут использовать другой каталог.

Обязательны manifest.json, main.lua, gen2.lua, field_user.lua, town_map.lua,
lighting.lua. Остальные файлы — документация. Требуется engine_internals:
адаптер использует внутренние функции движка, но не заменяет файлы игры.

## Настройки

MODS → Modern Field Moves → OPTIONS..

| Настройка | Значения | Поведение |
| --- | --- | --- |
| FIELD MOVE USER | GENERIC (default) | CUT was used!, SURF was used! и т. п., без имени |
| FIELD MOVE USER | KNOWN MOVE | Имя первого знающего приём покемона; без знатока — GENERIC |
| FIELD MOVE USER | FIRST PARTY | Первый покемон команды независимо от атак; яйца пропускаются |
| HM REQUIREMENT | HM + BADGE (default) | Нужны диск и соответствующий значок |
| HM REQUIREMENT | BADGE ONLY | Нужен только соответствующий значок |
| HM REQUIREMENT | UNRESTRICTED | Debug/cheat: игнорировать только требования HM и значка для полевых HM |
| LIGHT MODE | MANUAL (default) | LIGHT в START только в настоящей неосвещённой тёмной области |
| LIGHT MODE | AUTO | Автоматическое освещение без диалога после завершения занятого состояния |
| CONFIRM PROMPTS | ON (default) | Обычные подтверждения контекстных действий |
| CONFIRM PROMPTS | OFF | Cut/Surf/Strength/Whirlpool/Waterfall выполняются без вопроса YES/NO |

Fly всегда требует YES/NO, в том числе при OFF + UNRESTRICTED. OFF не убирает
сообщения о применении, анимации, сюжетные вопросы или выбор удочки в меню QoL.
Настройки переключаются без перезапуска; после замены файлов перезапуск обязателен.

UNRESTRICTED не выдаёт значки, диски, карту или Map Card, не открывает города,
не отменяет ограничения местности и не снимает сюжетные проверки значков вне HM.

GENERIC не назначает именованного исполнителя в сообщениях. Для родного кода
анимаций всё ещё передаётся реальный покемон; нужна непустая команда, в Gen 2 —
хотя бы один не-яйцо. Атаки, PP, HP и боевые механики мод не меняет.

## Управление и требования по умолчанию

| HM | RBY: значок | G/S/C: значок | Использование |
| --- | --- | --- | --- |
| HM01 Cut | Cascade | Hive | A у дерева |
| HM02 Fly | Thunder | Storm | TOWN MAP / MAP → посещённый город → YES/NO |
| HM03 Surf | Soul | Fog | A у воды |
| HM04 Strength | Rainbow | Plain | A у валуна, затем толкать |
| HM05 Flash | Boulder | Zephyr | LIGHT в темноте или AUTO |
| HM06 Whirlpool | — | Glacier | Во время плавания A перед водоворотом |
| HM07 Waterfall | — | Rising | Во время плавания A перед водопадом, лицом вверх |

В Gen 2 HM учитываются в сумке и PC. В RBY учитывается сюжетный факт получения
или предмет в сумке: полученный обычным способом HM можно хранить в PC.
В HM + BADGE одного диска или одного значка недостаточно.

## Карта и Fly

RBY: TOWN MAP появляется после настоящего Town Map от Daisy. Учитывается
EVENT_GOT_TOWN_MAP; старые saves поддерживаются также через предмет в Bag/PC.
Сдача карты в PC не убирает пункт меню.

Gold/Silver/Crystal: MAP появляется после штатной Map Card от Guide Gent
в Cherrygrove. Используется ENGINE_MAP_CARD, разрешаемый движком по имени;
поддерживается и старое pokegearFlags.map.

Без Fly карта работает для просмотра. После открытия Fly сохраняется полная
карта с названиями дорог и городов: вверх/вниз — перемещение курсора, B — выход.
A на доступной посещённой Fly-точке открывает подтверждение. A на дороге или
недоступном городе ничего не запускает. NO/B в подтверждении сохраняет курсор.
Перед YES требования и список разрешённых точек проверяются повторно.
Родные анимации, ограничения помещений и регионов Джото/Канто сохранены.
Отдельного FLY в START нет. UNRESTRICTED не заменяет получение карты.

## LIGHT и различия Gen 2

MANUAL: LIGHT появляется только при необходимом и доступном освещении, после
применения исчезает. Действие называется FLASH: в GENERIC — FLASH was used!.
Дополнительного подтверждения после ручного выбора LIGHT нет.

AUTO: обычная тёмная область освещается без диалога, когда игрок свободен.
Работает при входе, загрузке в пещере или переключении настройки внутри неё.
Повторного применения каждый кадр нет. Обычная ночь не считается темнотой.
Проверка использует состояние палитры/flashUsed, не опрашивает field actions.

Только Crystal: комната Aerodactyl исключена из LIGHT/AUTO; до открытия стены
там доступен отдельный явный FLASH. AUTO никогда не запускает эту загадку.
Gold/Silver: этой Crystal-загадки нет. Дополнительного FLASH в START нет,
и обработчик Flash не вызывает Crystal callback и не записывает его event flag.

Один gen2.lua обслуживает Gold, Silver и Crystal. Различия индексов флагов и
landmarks разрешает родной движок через данные выбранной игры. Различие
родной проверки Surf перед NPC (исправление Crystal) сохранено, а не перенесено
на G/S принудительно. Новых карт, способностей или боевых изменений нет.

## Проверки и ограничения

Проверенный исходный код gen1recomp dev:
`e2114f7c85795d52903ea98deab493a4f181bace`.

Автоматические тесты запускают настоящий Lua-код движка под LuaJIT 2.1 отдельно
для каждой из шести версий, с синтетическими сохранениями/картами и заглушками
графики. Покрываются HM, режимы настроек, карта, Fly, LIGHT, ограничения,
сохранение настроек, совместимость с Quality of Life 1.3.0 и версия-зависимые флаги.
Проверки длины GENERIC-строк не заменяют визуальную проверку реального шрифта.

Полный игровой прогон с ROM Gold/Silver и визуальная проверка не выполнялись.
Смотрите MANUAL_CHECKLIST_RU.md: обе игры нужно проверить отдельно, включая
реальные карты, анимации, переходы и сохранение/загрузку. Релиз собран как 1.0.0,
но считать его полностью проверенным в игре можно только после этого прогона.
Внутренние API могут измениться в новых сборках gen1recomp.

При QoL сохраняются его настройки: например, меню выбора Surf/удочки и его
быстрые взаимодействия могут заменять обычный вопрос. Второй обработчик
взаимодействия Gen 1 в Gen 2 не устанавливается.

Подробности проверки исходников и итоговые числа тестов: RELEASE_REPORT_RU.md.
Для отключения выключите мод и перезапустите игру, желательно стоя на суше.
