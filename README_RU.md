# Field Moves — Red & Blue v0.3.2

Все пять HM Pokémon Red и Blue без обучения покемонов. Mod API 2. Yellow пока не поддерживается.
Рабочие файлы: manifest.json и main.lua. Другие моды не обязательны.

## Установка

Импортируйте field_moves_red_blue-v0.3.2.zip через MODS → Import mod .zip,
замените предыдущую версию и полностью перезапустите игру.
В списке: Field Moves - Red & Blue. Включите мод отдельно для Blue через Show for. ID остаётся surf_without_hm_red.
При ручной установке замените файлы внутри прежней папки, не создавая дубликат.
На проверенной установке пользователя каталог:
%APPDATA%\pokemon-love2d\mods\surf_without_hm_red\.
У portable-сборок расположение может отличаться.

## Требования и управление

| Способность | Диск | Значок | Использование |
| --- | --- | --- | --- |
| Cut | HM01 | Cascade Badge, Misty | A у дерева → подтверждение; QoL может сразу срубить |
| Fly | HM02 | Thunder Badge, Lt. Surge | START → FLY → родная карта посещённых городов |
| Surf | HM03 | Soul Badge, Koga | A у воды → подтверждение или меню Surf/удочка от QoL |
| Strength | HM04 | Rainbow Badge, Erika | A у валуна → YES/NO; с Easy Interactions QoL активируется сразу |
| Flash | HM05 | Boulder Badge, Brock | START → FLASH в тёмной пещере |

Для каждой способности нужны одновременно полученный диск и соответствующий
значок. Ни один значок сам по себе ничего не открывает. Полученные диски
можно хранить в PC: сюжетный флаг сохраняет доступ. Если диск добавлен в
сумку редактором сохранения, положительное количество предмета также считается
наличием HM. При удалении такого предмета без сюжетного флага доступ пропадёт.

HM05 Flash в Red выдаёт помощник Оука в здании на Route 2 за 10 пойманных
видов (не 20). Счётчик пойманных видов мод не использует: сначала необходимо
получить сам HM05. Заполненная сумка и незабранная награда не открывают Flash.

Для Cut/Surf используются штатные проверки местности, затем штатные действия.
Cut также сохраняет нативную возможность косить подходящую траву.
Strength после активации позволяет двигать валуны обычным способом; его
состояние на карте обслуживает движок. Flash не активируется на свету или
повторно в уже освещённой пещере. Неприменимый пункт START выводит сообщение.
В START нет Cut, Surf и Strength. Строки Fly/Flash появляются после открытия
соответствующей способности; длинное меню прокручивается штатно.

## Имя покемона в тексте

Это ожидаемое поведение текущего мода. Родные Surf, Cut и Strength используют
имя покемона в сообщениях. Если в команде никто не знает приём, мод передаёт
первого покемона как исполнителя. Если кто-то знает приём, движок предпочитает
его. Это не обучение: список атак, PP, HP и вид не меняются. Совместимость
вида с HM не требуется; команда должна быть непустой. В Gen 1 полевые
приёмы допускаются и у покемонов без HP.

## Quality of Life

Сохранено исправление v0.2.1: наш обработчик A выполняется после QoL,
а штатный API не предлагает действие, когда другое меню уже заняло экран.
При включённых водных взаимодействиях QoL остаётся его меню Surf/рыбалка;
если они выключены — наш Surf across? с YES/NO. Для Cut действует такой же
приоритет. Strength работает по A у валуна и без QoL (YES/NO). С Easy Interactions QoL
сохраняется немедленная активация без второго окна. Настройки QoL не изменяются.

## Что проверить в игре

1. С одним значком, но без соответствующего HM, способность недоступна.
2. Заберите HM: способность открывается, обучать покемона не нужно.
3. Cut: A у дерева; с отключённым QoL проверьте YES и NO.
4. Strength: нажмите A у валуна, подтвердите при необходимости, затем толкните его.
5. Flash: с HM05 и Boulder Badge войдите в тёмную часть Rock Tunnel и выберите
   START → FLASH. После закрытия текста пещера должна осветиться.
6. Сдайте полученный HM в PC: способность остаётся. Проверьте, что атаки
   команды не поменялись и Surf не показывает второго вопроса под меню QoL.

- 31: Strength по A, YES/NO, обычные NPC, декорации, требования, оба порядка QoL;

проверены через штатные изменения состояния. Полный игровой прогон v0.3.2
