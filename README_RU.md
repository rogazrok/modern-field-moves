# Surf Without Teaching — Red v0.1.0

Минимальный прототип для Pokémon Red в gen1recomp (mod API 2).
Рабочие файлы мода: manifest.json и main.lua. Этот README — инструкция.
Зависимостей от других модов и дополнительных разрешений нет.

## Что делает

После получения HM03 Surf и Soul Badge Коги в START появляется SURF.
Встаньте на берегу лицом к воде, выберите START → SURF и закройте штатный
текст посадки. Движок выполняет обычный Surf. Подтверждение YES/NO и
запуск нажатием A у воды в эту версию не входят. Fly не добавлен.

Ни одному покемону не нужно учить Surf. Для штатного текста посадки движку
передаётся первый покемон команды, независимо от вида и совместимости с HM.
Если в команде уже есть покемон с Surf, предпочтение отдаётся ему.
Команда должна быть непустой. Обморок выбранного покемона не запрещает
полевой приём, как и в исходной реализации Gen 1.
Приёмы, PP и виды покемонов не меняются. Новые данные в сохранение не записываются.

Прогресс: SOULBADGE и либо EVENT_GOT_HM03, либо положительное количество
HM_SURF в инвентаре. Сюжетный флаг позволяет хранить уже полученный HM в PC.
Без получения HM способность не открывается даже у импортированного
покемона с выученным Surf. Остальные полевые приёмы сохраняют штатные проверки.

## Установка

1. В лаунчере gen1recomp откройте MODS → Import mod .zip и выберите
   surf_without_hm_red-v0.1.0.zip. Можно перетащить архив на окно лаунчера.
2. В Show for выберите Red и включите Surf Without Teaching - Red.
3. Запустите Pokémon Red. После изменения модов внутри игры примените
   APPLY & RESTART; менеджер модов открывается клавишей F10.

Альтернатива: распакуйте папку surf_without_hm_red в mods в каталоге
сохранений приложения. Для обычной Windows-сборки со стандартным LÖVE
save directory это %APPDATA%\LOVE\pokemon-love2d\mods\.
Путь может отличаться у portable-сборки или при переопределении identity.
При запуске из исходников можно использовать <каталог движка>/mods/.

Итоговая вложенность:

    mods/
      surf_without_hm_red/
        manifest.json
        main.lua
        README_RU.md

## Проверка в игре

Для сравнения удобно использовать отдельный слот сохранения и отключить
другие моды, меняющие полевые приёмы.

1. Возьмите сохранение после получения HM03 в Safari Zone и Soul Badge.
   В команде оставьте покемонов без Surf; учить приём не нужно.
2. Подойдите к обычному доступному берегу, например к воде на юге Pallet Town,
   и повернитесь к воде. Откройте START (по умолчанию Escape).
3. Выберите SURF (A по умолчанию Z/Enter/Space). Должен появиться штатный
   текст посадки с именем покемона. После закрытия текста герой входит в воду.
4. Поплавайте и выйдите на сушу. Список приёмов команды должен остаться прежним.
5. Проверьте сохранения без значка и без полученного HM: пункта SURF быть не должно.
6. После сдачи HM в PC пункт остаётся. На суше вдали от воды действие показывает
   Can't SURF here! и не перемещает героя. Ограничения Cycling Road и течений
   Seafoam остаются у движка.

SURF отображается после открытия способности и вдали от воды: точное место
повторно проверяется при выборе пункта. Он также может вызвать штатный выход
из воды, когда герой уже плывёт и смотрит на допустимый берег.

## Совместимость и проверка

Сверено 17 сентября 2026 с веткой dev gen1recomp, commit
e2114f7c85795d52903ea98deab493a4f181bace (16 сентября 2026).
Минимальная поддерживаемая релизная версия не устанавливалась экспериментально.
Нужна сборка с mod API 2, fieldmove.eligibility, ui.start_menu.items и
mod.world:useFieldAction. В старой сборке без useFieldAction мод выдаст ошибку
загрузки с пояснением. Blue/Yellow/Gen 2 не объявлены поддерживаемыми.

Локально пройдено 21 проверка под LuaJIT 2.1, включая настоящий
Manifest.validate, Hooks, Menu, OverworldController.useSurfFieldMove и WorldAPI.
В тестах использованы синтетическое сохранение и заглушка LÖVE; сам эффект
посадки/выхода заменён контрольным вызовом. ROM, визуальная анимация, реальная
карта и загрузка через установленный лаунчер здесь не проверялись.
Это готовый к установке прототип с проверенной логикой, требующий прогона в игре.
